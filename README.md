# VikBooking Turkish Translation (AI-Assisted)

This repository contains the Turkish language file (`.po`) for the latest version of the WordPress hotel and booking plugin, **VikBooking**.

I translated this plugin into Turkish using AI tools out of necessity for a hotel website project I am currently developing. I am sharing it as open-source so that other web designers and site owners building similar projects—whether on local servers or in live environments—can also benefit from it.

## 🚀 Features
* Compatible with the latest version of the VikBooking plugin.
* Highly comprehensive and clear, thanks to AI-assisted translation.
* Covers both the admin panel (backend) and the user interface (frontend - booking forms, etc.) text strings.

## 🛠️ Installation & Usage

Adding the translation files to your site is quite simple. Please follow the steps below in order:

1. Download the `vikbooking-tr_TR.po` file from this repository to your local machine.
2. Access your website's file system (via FTP, cPanel, or your `htdocs`/`www` folder if using a local server).
3. Copy the file exactly into the following directory:
   `wp-content/languages/plugins/`
4. Ensure that your site language is set to **Türkçe (Turkish)** in your WordPress General Settings.

> **⚠️ IMPORTANT NOTE:** **DO NOT** upload the files directly into the plugin's own translation folder (`wp-content/plugins/vikbooking/languages/`). If you do, your Turkish translation files will be overwritten and lost the next time the VikBooking plugin is updated. By placing them in the `wp-content/languages/plugins/` directory as specified above, your translations will remain safe and persistent.
